# 실제 로컬 BE 방문 지도 E2E 검증

검증일: 2026-11-15

**결과는 통과이며, 이번 검증 범위에서 FE 추가 수정이 필요한 문제는 발견되지 않았다.** PR #61의 커밋 `b72da4a`에 있는 애플리케이션을 실제 `localhost:8080` BE와 연결했다. 로그인·주소·위치·도보 응답을 모의 데이터로 대체하지 않았고 인증 저장소도 우회하지 않았다.

검증용 지역과 회차, 서울시청·덕수궁의 공공 주소를 사용한 매물 두 건을 UI로 생성했다. 기존 사용자 기록은 수정하지 않았다. 검증 후 생성한 데이터는 모두 삭제하고 재조회로 정리를 확인했다.

## 확인 결과

| 사례 | 실제 결과 |
| --- | --- |
| 로그인 UI | `POST /users/login` 200, 보호 화면 진입 |
| 주소 검색 | `GET /geo/addresses` 200, 후보 2건. 건물관리번호와 5개 좌표 조회 키가 FE 계약과 일치 |
| 주소를 선택한 매물 생성 | 두 매물 모두 200. 요청에는 `bdMgtSn`, `roadAddress`, `coordKey`만 포함하고, 응답에 저장된 WGS84 위경도가 반환됨 |
| 새로고침 후 매물 상세 | 200, 저장한 위치 유지 |
| 메모만 수정 | PUT 200. 기존 건물·좌표가 그대로 유지되고, 위치 요청은 건물관리번호·주소만 포함 |
| 위치 해제 | PUT 200, 새로고침 후에도 `location: null` 유지 |
| 주소 재지정 | PUT 200, 새로고침 후에도 지정한 위치 유지 |
| 도보 경로 요청 | 본문 없는 POST 1회, 200. 지점 2개·구간 1개와 유효한 경로 좌표 반환 |
| 도보 거리·시간 표시 | BE의 234m·243초를 화면에서 `실제 도보 약 5분 · 234m`로 표시 |
| 자동·중복 도보 호출 | 클릭 전 0회. 모바일 화면으로 이동한 뒤에도 전체 도보 호출 1회 유지 |
| 모바일 회차 재진입 | 이전 패널의 도보 응답을 유지하지 않고 기본 직선으로 복귀 |
| 실제 지도·폰트 | PC 1440px에서 지도 타일 16개, 모바일 390px에서 7개 로드. 지도·편집 화면의 한글 Pretendard 확인 통과 |
| 가로 넘침 | 지도·편집 화면에서 PC `scrollWidth=1440`, 모바일 `scrollWidth=390` |
| 테스트 데이터 정리 | 회차 삭제 204, 지역 삭제 204. 검색 일치 지역 0건, 생성한 회차·매물 재조회에서 NOT_FOUND 확인 |

스크린샷은 메인 에이전트가 직접 열어 지도선·번호·거리·시간·주소 편집과 반응형 배치를 확인했다. 제품 코드 변경은 없으며 실제 E2E 결과와 캡처만 추가한다.

검증은 기존 미커밋 인증 작업과 분리한 PR 소스에서 수행했다. 임시 분리 서버의 5174 Origin 로그인은 403이었으므로, 실제 성공 검증은 기존 개발 Origin인 `http://localhost:5173`에서 진행했다. 공유 설치 디렉터리의 폰트를 읽기 위한 Vite 파일 허용 설정은 임시 서버에만 적용했으며 저장소의 Vite 설정은 변경하지 않았다.

실제 유료 도보 요청은 작은 구간 1회만 수행했다. 쿼터 소진·외부 제공자 장애·타임아웃은 실제로 유발하지 않았으며, 해당 분기는 기존 단위·모의 API 검사 범위다. 운영 배포 환경과 다른 사용자의 엄격한 동시 수정도 이번 로컬 E2E 범위에 포함하지 않았다.
