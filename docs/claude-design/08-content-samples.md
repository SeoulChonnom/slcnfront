# 콘텐츠 샘플

## 사용법

- 이 문서의 모든 값은 **가상 데이터**다. 실제 사용자·주소·단지·상호와 무관하며, 화면에 들어갈 데이터의 **분량·형식·극단값**을 가늠하기 위한 참고 자료다. 디자인 지시가 아니다.
- 기능은 `00-common.md` ~ `07-profile.md`의 기능 ID(TRV-01 등)로 연결한다.
- 분량 표 "근거" 열의 **코드**는 입력 검증·서버 한도처럼 코드로 확정된 값, **가정**은 코드로 확정할 수 없어 현실적으로 추정한 값이다. 가정 값은 실제와 다를 수 있으니 여유를 두고 본다.
- "최대"는 "깨지지 않아야 하는 현실적 상한"이다. 코드가 상한을 두지 않은 곳은 그 값을 넘는 입력도 가능하다.
- 서비스 이름이 들어갈 자리는 `[서비스명]`, 사용자는 `사용자 A`처럼 쓴다.

## 공통

### 날짜·시간 표기

| 쓰임 | 형식 | 예 |
|---|---|---|
| 날짜 (여행·나들이·임장 목록) | `YYYY.MM.DD` | 2026.09.12 |
| 날짜 범위 (여행) | `YYYY.MM.DD – YYYY.MM.DD` (en dash, 앞뒤 공백) | 2026.09.12 – 2026.09.14 |
| 기간 길이 (여행) | `N박 M일` (당일치기는 0박 1일) | 2박 3일 |
| 여행 상세 일차 | `N일차`, `MM.DD · 요일 한 글자` | 2일차 / 09.13 · 일 |
| 앨범 묶음 소제목 | `N일차 · YYYY.MM.DD` | 3일차 · 2026.09.14 |
| 임장 일시 | `YYYY.MM.DD hh:mm` (24시간, 시간대 없음) | 2026.09.17 14:00 |
| 임장 목록의 예정·최근 | `MM.DD` / `yyyy.mm.dd 요일 hh:mm` | 예정 10.18 / 2026.10.04 토 09:30 |
| 임장 저장 상태 | `{hh}:{mm}에 임시 저장됨` | 14:07에 임시 저장됨 |
| 달력 월 제목 | `YYYY년 M월` | 2026년 10월 |
| 달력 주 제목 | `M월 D일 - D일` / 달이 걸치면 `M월 D일 - M월 D일` | 10월 11일 - 17일 / 9월 28일 - 10월 4일 |
| 달력 목록 구역 제목 | `M월 D일 (요일) 일정` | 10월 14일 (수) 일정 |
| 달력 시각 (목록) | `오전/오후 h:mm` 또는 `종일` | 오후 2:30 |
| 홈 다음 일정 시각 | `HH:mm` / `하루 종일` / 시각 불명 `일정` | 19:30 |

### 숫자·단위 표기

| 항목 | 형식 | 예 |
|---|---|---|
| 가격 (신발) | 천 단위 쉼표 + `원`, 문자열 그대로 | 149,000원 |
| 도보 거리 | 1km 미만 `m`, 이상 `km`(소수 1자리) | 420m / 1.3km |
| 도보 시간 | `약 N분` | 약 6분 |
| 개수 | 숫자 + 단위 붙여 씀 | 남긴 나들이 12개 / 매물 4건 / 사진 6장 |
| 관심도 | 1~5 정수 | 4 |
| 회차 | `N차`, 계획은 번호 없이 `계획` | 3차 · 가장 최근 |
| 태그 | `#태그` 로 표시 (저장 값에는 `#` 없음) | #한옥 |
| 초과 표기 | `+N` | +2 |

### 이미지

| 종류 | 쓰임 | 제공 크기 변형 | 형식·용량 |
|---|---|---|---|
| 여행 대표 사진 | 홈 대표(큰 크기), 홈·여행 목록(작은 크기), 상세 상단 | 큰 크기 / 작은 크기 / 원본 | jpg·jpeg·png, 장당 50MB 이하 (코드) |
| 여행 앨범 사진 | 상세 앨범, 날짜·장소 썸네일 | 위와 동일 | 동일, 장수 상한 없음, 캡션 선택 (코드) |
| 나들이 로고 / 경로 지도 | 목록 썸네일 / 상세(최대 2장) | 위와 동일 | 10MB 이하 (코드) |
| 임장 회차·매물 사진 | 지역 목록 썸네일, 회차·매물 갤러리 | 위와 동일 | 서버 파일당 50MB (코드) |
| 신발·후기 이미지 | 신발 목록·상세·후기 | 변형 없음 (정적 파일 또는 외부 주소) | — |

- 크기 변형의 실제 픽셀 규격은 코드로 확정되지 않는다(미확인). 원본 비율은 가로형·세로형·정사각형이 모두 들어온다고 가정한다(가정).
- 사진이 없거나 불러오기에 실패한 경우는 "사진 없음" 상태로 통일한다(깨진 이미지 금지).
