# 임장 — 주소 검색·위치 저장·지도·방문 순서·도보 경로·추천 정렬, 매물 상세

> 상위 문서: [04-inspection.md](./04-inspection.md) (개요·URL·데이터 필드 사전·기술 제약·확인 필요). 이 파일의 기능 ID는 전체 임장 영역에서 유일하다.

## 기능 목록
### INS-18 방문 순서(지도·목록) 보기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 회차 내용(지역 상세)과 등록 마법사 3단계의 "방문 순서" 영역 (매물이 1건 이상일 때)
- **흐름**:
  1. 영역은 기본 펼침이고 "접기/펼치기"로 토글한다.
  2. 위치가 저장된 매물을 화면 순서대로 번호를 붙여 지도에 표시하고 구간을 직선으로 잇는다. 번호는 **위치가 없는 매물을 포함한 전체 목록에서의 순번**이다(위치 없는 매물은 번호만 비우고 지도에 표시 안 함). **연속된** 같은 주소(건물)의 매물은 한 지점으로 합쳐 "2·3"처럼 표시.
  3. 지도 옆에 같은 정보를 목록으로 보인다: 번호, "단지명 · 동·호수"(합쳐진 지점은 " / "로 이음), 다음 지점까지 "다음까지 {거리} · 약 {n}분"(건너뛴 번호가 있으면 "{번호}번 지점까지 …").
  4. 합계 줄: 직선 기준일 때 "총 {거리} · 약 {n}분 (직선 기준 추정)". 거리 표기는 1km 미만 m, 이상 km(소수 1자리).
  5. 위치가 저장되지 않은 매물이 있으면 "위치 미지정 {n}건".
- **표시 데이터**: 번호, 이름, 구간 거리·시간, 지도(마커·선), 지도 하단 출처 문구 현재 문구: "주소·좌표: 행정안전부"
- **상태**:
  - 지도 사용 불가(지도 키 없음, 지도 스크립트 로딩 실패): **지도만 생략하고 목록은 그대로 제공**해야 한다.
  - 위치가 저장된 매물이 없음: 현재 문구: "위치가 저장된 매물이 아직 없어요." (지도 없음)
  - 접힘: 본문 숨김.
- **결과**: 없음(조회)
- **정책·예외 규칙**:
  - 순서는 항상 화면(서버 배열) 순서이며 이 영역이 순서를 바꾸지 않는다. 직선 추정은 직선 거리×1.3, 시속 4.5km, 올림 분 단위.
  - 지도에서 좌표를 찍거나 주소를 새로 고르는 기능은 없다(보기 전용). 지도 SDK의 로고·저작권 표기를 가릴 수 없다.
- **데스크톱/모바일 차이**: 없음(지도 높이만 다름)
### INS-19 도보 경로 보기 / 직선으로 보기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: "방문 순서" 영역의 "도보 경로 보기" 버튼 (위치가 있는 지점이 2곳 이상일 때만 표시)
- **흐름**:
  1. 누르는 순간에만 실제 도보 경로를 서버에 요청한다(자동 조회 없음, 외부 유료 조회). 처리 중 버튼 문구 "도보 경로 불러오는 중…"(비활성).
  2. 성공하면 지도와 목록이 실제 도보 경로(선·구간 거리·시간)로 바뀌고, 합계 줄이 "실제 도보 약 {n}분 · {거리}"가 된다. 버튼은 "직선으로 보기"로 바뀌어 직선 표시로 되돌릴 수 있다.
  3. 같은 상태에서 다시 "도보 경로 보기"를 누르면 재요청 없이 이미 받은 경로를 다시 보인다.
  4. 완료된 회차에서 경로를 보면 안내 문구 현재 문구: "화면 순서대로 걸었을 때의 현재 기준 추천 경로예요" (실제로 걸은 길이 아님).
- **상태**:
  - 한도 초과: 현재 문구: "오늘 경로 조회 한도를 넘었습니다"
  - 서버 실패/기타: 현재 문구: "잠시 후 다시 시도해 주세요"
  - 기능 꺼짐: 현재 문구: "지금은 도보 경로를 볼 수 없어요" — 이 화면이 열려 있는 동안 버튼 비활성
  - 경로를 그릴 지점이 부족: 현재 문구: "경로를 그릴 지점이 2곳 이상 필요해요"
  - 실패해도 직선 표시는 유지된다.
- **결과**: 경로는 화면에만 있고 저장하지 않는다.
- **정책·예외 규칙**: 방문 순서나 매물 주소가 바뀌면 받아 둔 경로는 버리고 직선 표시로 돌아간다. 실제 걸은 길을 기록하지 않으며 회차를 다시 열면 다시 요청해야 한다. 호출에 하루 한도가 있다(기술 제약).
- **데스크톱/모바일 차이**: 없음
### INS-20 현재 위치 기준 추천 순서로 정렬
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 회차 내용(지역 상세)과 등록 마법사 3단계의 "추천 순서로 정렬" 버튼 (매물 1건 이상, **완료된 회차에서는 표시하지 않음**)
- **흐름**:
  1. 위치가 있는 매물이 서로 다른 주소로 2곳 미만이면 버튼 비활성이고 안내 현재 문구: "위치가 있는 매물이 2곳 이상 필요해요"
  2. 누르면 화면 이동 없는 별도 단계가 열린다. 제목 "추천 순서로 정렬", 설명 "현재 위치에서 가까운 순서로 방문 순서를 추천해요".
  3. "현재 위치"를 **주소 검색으로 입력**한다(INS-41과 같은 주소 검색, 기기 위치 권한 사용 안 함). 후보를 고르면 서버에서 좌표를 확인한다("위치를 확인하는 중…", 그동안 입력 비활성). 좌표는 이 단계가 열려 있는 동안 화면 메모리에만 두고 닫으면 버린다.
  4. 선택 "출발지로 돌아오기"를 켜면 출발지로 돌아오는 닫힌 경로 기준으로 계산한다.
  5. 위치가 확인되면 미리보기를 보인다: "현재 순서 {거리} → 추천 {거리}", "직선 기준 추정", 방문 순서 지도(현재 위치는 "출발" 표시, 현재 위치→첫 지점은 점선 직선)와 추천 순서 목록("단지명 · 동·호수"). 위치가 없는 매물이 있으면 "위치 미지정 {n}건은 마지막에 배치됨".
  6. "적용"을 누르면 추천 순서가 회차의 방문 순서로 저장된다. 성공하면 현재 문구: "추천 순서를 적용했어요"와 "되돌리기"가 나타난다(적용 버튼 비활성). "되돌리기"는 적용 전 순서로 복원한다.
  7. "닫기"로 닫는다.
- **상태**:
  - 이미 가장 짧음(추천 순서가 현재와 같거나 더 줄지 않음): 현재 문구: "지금 순서가 이미 가장 짧아요", 적용 비활성.
  - 좌표 없음: 현재 문구: "이 주소는 좌표가 없어요. 가까운 다른 건물을 골라 주세요"
  - 주소 확인 실패/기타: 현재 문구: "주소 확인에 실패했어요. 잠시 후 다시 시도해 주세요"
  - 주소 기능 꺼짐: 현재 문구: "지금은 주소를 쓸 수 없어요" — 이 단계의 주소 입력 비활성
  - 순서 저장/복원 실패: 현재 문구: "순서를 바꾸지 못했어요. 원래 순서로 되돌렸어요. 잠시 뒤 다시 시도해 주세요"
  - 적용·되돌리기 처리 중에는 두 버튼 비활성. 위치를 새로 고르면 이전의 적용 완료 표시는 지워진다. "위치 지우기"는 미리보기를 지운다.
- **결과**: 방문 순서가 서버에 저장되어 방문 순서 영역·확인 매물 목록의 순서와 번호가 갱신된다. 먼저 화면을 바꾸고 실패하면 원래 순서로 복구.
- **정책·예외 규칙**:
  - 현재 위치는 저장·기록하지 않는다(주소를 좌표로 바꾸는 조회만 서버로 보냄).
  - 같은 좌표의 매물은 한 지점으로 묶여 함께 이동한다. 위치 없는 매물은 항상 맨 뒤.
  - 계산: 지점 8곳 이하 완전 탐색, 13곳 이하 정확한 동적 계획법, 그 이상은 근사. 거리는 직선×1.3 보정. 동률이면 화면 순서가 앞선 쪽을 유지.
  - 되돌리기는 원래 순서값이 순서를 그대로 나타낼 때는 원래 값을, 아니면 0부터 다시 매긴 값을 쓴다.
- **데스크톱/모바일 차이**: 없음
### INS-41 주소 검색해 고르기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 매물 추가(INS-40), 매물 편집(INS-65), 추천 순서의 현재 위치(INS-20)
- **흐름**:
  1. 입력창(안내 "가까운 건물이나 주소를 입력하세요")에 2자 이상 입력하면 입력이 멈춘 약 0.3초 뒤 도로명주소 후보를 검색한다(2자 미만은 요청 없음).
  2. 후보 목록이 나타난다. 각 후보: 도로명주소(없으면 지번주소)와 건물명(있으면). 후보를 누르거나 키보드 위/아래 화살표로 이동 후 Enter로 고른다. Esc로 목록을 닫는다.
  3. 고르면 선택된 주소(도로명주소, 없으면 "선택한 주소")가 입력을 대신 보이고 "변경"(다시 검색, "취소"로 원복)과 "위치 지우기"(주소 해제)를 제공한다.
- **상태**:
  - 결과 없음: 현재 문구: "검색 결과가 없어요"
  - 검색어 거부(서버 검증 실패): 서버가 준 사유 문구를 입력 오류로 표시
  - 기능 꺼짐: 현재 문구: "지금은 주소를 쓸 수 없어요" — 입력 비활성
  - 그 밖의 검색 실패는 별도 문구 없이 목록이 비어 있음(확인 필요)
- **결과**: 선택값(건물관리번호, 도로명주소, 좌표 조회 키)을 호출한 화면에 넘김. 좌표는 FE가 직접 보내지 않고 서버가 확정한다.
- **정책·예외 규칙**: 검색 결과는 행정안전부 도로명주소 데이터이며 저장 가능한 출처다. 지도 사업자(카카오 등)의 검색 결과로 좌표를 얻어 저장하는 것은 약관상 금지이므로 대체하면 안 된다. 같은 검색어는 1분간 다시 요청하지 않는다.
- **데스크톱/모바일 차이**: 없음
### INS-60 매물 상세 보기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 확인 매물 목록의 매물 선택, 같은 이름 다른 회차 묶음의 항목, 이전/다음 매물 이동
- **표시 데이터**:
  1. 상위 경로: 임장 › {지역명} › {yyyy.mm.dd} 임장(해당 회차 선택 상태의 지역 상세로) › {단지명 동·호수}.
  2. 헤더: 단지명, 동·호수(제목, "동·호수 미정" 가능), 저장된 도로명주소(있을 때), 관심도 별+요약. 동작: "삭제"(INS-63), "매물 수정"(INS-64).
  3. 같은 이름 다른 회차 묶음(INS-61) — 동·호수가 있을 때만.
  4. 메모, 한줄평(따옴표), 태그 전부, 장점("+ 장점")/단점("− 단점") 줄 단위 목록(있는 쪽만).
  5. 매물 사진(제목 "매물 사진", "{n}장", 캡션=대체 텍스트).
  6. 문답(제목 "문답", "필수 {n}개 · 선택 {m}개"): 저장된 분류별로 묶고 분류·질문 순으로 나열. 질문마다 라벨 "필수/선택 · {유형}"(유형 표시: 숫자, 단일 선택, 다중 선택, 예/아니오, 별점; 텍스트류는 생략), 질문 문구, 답변. 답변 표시: 글, 숫자+단위, 별점, 예/아니오, 선택한 보기 문구(보기가 사라졌으면 코드 그대로). 미답변이면 필수는 현재 문구 "아직 작성하지 않았습니다"(경고 표시), 선택은 "응답 없음". 질문이 이후 개정/비활성화된 경우 라벨에 "이 기록은 v{n} 질문 기준", "현재 미사용 질문"을 덧붙이되 표시 방식을 바꾸지는 않는다.
  7. 안내 현재 문구: "이 매물은 {yyyy.mm.dd} 임장 시점의 질문 구성으로 저장되어 있습니다. 이후 질문이 바뀌어도 이 기록의 문답은 그대로 유지됩니다."
  8. 이전/다음 매물 이동(INS-62).
- **상태**: 로딩 자리표시. 에러 현재 문구: "매물 정보를 불러오지 못했어요." / "잠시 후 다시 시도해 주세요." + 다시 시도.
- **결과**: 없음(조회)
- **정책·예외 규칙**: 문답은 매물을 만든 시점의 질문 스냅샷이다. 이 화면에는 주소 텍스트 외에 지도/위치 표시가 없다.
- **데스크톱/모바일 차이**: 없음
### INS-61 같은 이름 다른 회차 묶음 보기와 연결 해제
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 매물 상세 (동·호수가 있고 같은 지역에서 같은 단지명+동·호수 기록이 2건 이상일 때만 표시)
- **흐름**:
  1. 제목 "같은 이름으로 기록된 다른 회차", 설명 현재 문구: "{지역명}에서 단지와 매물명이 같은 기록을 자동으로 묶었습니다. 다른 집이라면 연결을 해제할 수 있습니다."
  2. 회차 최신순으로 날짜, 관심도, 변화 문구를 보인다. 변화 문구: 가장 오래된 행 "처음 본 회차", 관심도 비교 불가 "관심도 미입력", "{n}단계 올림", "{n}단계 내림", "변화 없음". 현재 보고 있는 기록에는 " · 지금 보는 기록"이 붙는다.
  3. 다른 회차 행을 누르면 그 매물 상세로 이동한다.
  4. "연결 해제"를 누르면 이 화면에서만 묶음이 숨겨진다.
- **정책·예외 규칙**: 연결은 단지명+동·호수의 정규화(공백 정리) 일치로 자동 추정한 것으로 확정된 동일성이 아니며, 해제는 서버에 저장되지 않아 화면을 다시 열면 돌아온다.
- **데스크톱/모바일 차이**: 없음
### INS-62 이전/다음 매물로 이동
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 매물 상세 하단(접근성 이름 "이전·다음 매물")
- **흐름**: 같은 회차 방문 순서 기준 이전 매물이 있으면 "← 이전 매물 · {동·호수}", 없으면 "← 이 임장의 매물 목록"(해당 회차 선택 상태의 지역 상세). 다음 매물이 있으면 "다음 매물 · {동·호수} →".
- **데스크톱/모바일 차이**: 없음
### INS-63 매물 삭제 (상세)
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 매물 상세 헤더의 "삭제"
- **흐름**: 확인 절차 제목 "매물을 삭제할까요?" / 현재 문구: "사진 {n}장, 태그 {m}개, 문답 응답 {k}개가 이 매물과 함께 삭제됩니다. 되돌릴 수 없습니다." / "삭제" / "계속 둘게요". 성공하면 해당 회차가 선택된 지역 상세로 이동.
- **상태**: 처리 중 삭제 버튼 로딩. 실패 안내 없음(확인 필요).
- **데스크톱/모바일 차이**: 없음
### INS-64 매물 편집 (기본 정보 자동 저장)
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 매물 상세의 "매물 수정", 확인 매물 목록(마법사)의 "이어서 쓰기"/"수정", 매물 추가 직후
- **흐름**:
  1. 상위 경로 "{지역명} · {yyyy.mm.dd hh:mm}"(지역 상세로), 제목 "매물 편집".
  2. 기본 정보 편집은 입력이 멈춘 약 2초 뒤 자동 저장(열기만 해서는 저장 안 함, 떠날 때 대기분 즉시 전송). 문답은 별도로 같은 지연 후 묶어서 저장(INS-67).
  3. 하단 동작: "매물 삭제"(INS-70), "작성 중으로 저장"과 "매물 완료"(INS-69).
- **입력 항목**:
  | 항목 | 형식 | 필수 | 제약·검증 | 현재 에러 문구 |
  |---|---|---|---|---|
  | 단지/건물명 | 텍스트(같은 지역의 기존 단지명 제안) | 예 | 안내 "같은 이름이어야 회차 간 매물이 연결됩니다." | 없음(완료 조건에서 검사) |
  | 동·호수 | 텍스트 | 완료 시 필수 | 안내 "임장 전에는 비워 둘 수 있지만, 작성을 마치려면 입력해야 합니다." | 완료 조건 안내 |
  | 주소 | 주소 검색(INS-65) | 아니오 | | INS-65 |
  | 관심도 | 별 1~5 선택 | 완료 시 필수 | 한 번 고르면 해제 동작 없음 | 완료 조건 안내 |
  | 메모 | 여러 줄(최대 5,000자) | 아니오 | | 없음 |
  | 한줄평 | 텍스트 | 아니오 | 안내 "선택 입력" | 없음 |
  | 장점 / 단점 | 여러 줄 | 아니오 | | 없음 |
  | 태그 | 태그 입력(Enter로 추가, × 로 삭제; 자주 쓴 태그 제안 없음) | 아니오 | 빈 값·중복 무시 | 없음 |
  | 매물 사진 | INS-51 | 아니오 | | |
  | 문답 | INS-67 | 질문별 | | |
- **상태**:
  - 로딩 자리표시. 에러 현재 문구: "매물을 불러오지 못했어요" / "삭제됐거나 잘못된 링크일 수 있어요." + 다시 시도.
  - 저장 실패: 서버 메시지 또는 현재 문구: "저장하지 못했어요. 잠시 뒤 다시 시도해 주세요."
  - 완료 조건 미충족 안내(상시): 현재 문구: "단지명·매물명·관심도와 필수 문답을 모두 채우면 완료할 수 있어요."
- **결과**: 저장된 값이 지역 상세·목록에 반영
- **정책·예외 규칙**: 서버는 매물 저장을 전체 교체 방식으로 받으므로 **위치를 항상 함께 보낸다**(화면의 값 유지, 없으면 해제). 이 값을 빼먹으면 위치가 지워진다.
- **데스크톱/모바일 차이**: 없음
### INS-65 매물 주소(위치) 지정·변경·해제
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 매물 편집의 "주소"
- **흐름**:
  1. 주소를 검색해 고른다(INS-41). 고르는 즉시(지연 없이) 저장을 시도한다.
  2. 이미 저장된 주소가 있으면 그 주소가 선택된 상태로 보이고 "변경", "위치 지우기"로 바꾸거나 해제한다. 해제도 즉시 저장.
  3. 같은 건물을 다시 저장하면 새 조회 없이 기존 좌표를 유지한다.
- **상태**:
  - 좌표 확인 실패 등으로 서버가 편집 저장 전체를 거부하면: 선택을 직전에 확정된 주소로 되돌리고 같은 내용을 위치 변경 없이 한 번 더 저장해 **다른 편집이 유실되지 않게** 한다. 주소 필드에 오류 현재 문구: "주소는 저장하지 못했습니다. {사유}". 사유: 좌표 없음 → "{서버 메시지}. 가까운 다른 건물을 고르거나 위치 없이 두세요", 조회 실패 → "주소 확인에 실패했어요. 잠시 후 다시 시도해 주세요", 기능 꺼짐 → "지금은 주소를 쓸 수 없어요".
  - 기능 꺼짐: 이 화면에서 주소 필드 비활성.
- **결과**: 저장된 위치가 방문 순서 지도·매물 상세 주소에 반영
- **정책·예외 규칙**: 주소·좌표 출처는 행정안전부이며 FE는 좌표를 직접 보내지 않는다. 사용자 기기 GPS/브라우저 위치 권한은 사용하지 않으므로 권한 거부 상황이 없다.
- **데스크톱/모바일 차이**: 없음
