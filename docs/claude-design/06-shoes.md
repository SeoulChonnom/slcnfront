# 신발 추천

## 개요
사용자는 운영자가 추천하는 신발을 브랜드별로 모아 보고, 신발 하나를 골라 가격·특징·참고 영상·착용 후기를 확인한다. 후기 항목은 외부 게시물(블로그, 인스타그램, 유튜브 등)로 연결된다. 이 영역은 서버 조회 없이 앱에 내장된 정적 목록을 보여주는 읽기 전용 영역이며, 필터·정렬·검색·등록·수정 기능은 없다.

## URL
| 경로 (/main, /mobile 공통 뒤쪽) | 화면 의미 | 접근 권한 | 비고 |
|---|---|---|---|
| `shoesRecom` | 신발 추천 목록(브랜드별 구역) | 로그인 사용자 전체 | |
| `:brand/:shoesName` | 신발 상세. `:brand`는 브랜드 식별 문자열, `:shoesName`은 신발 식별 문자열 | 로그인 사용자 전체 | 예 `nb/nb574`, `nike/v2k`, `asics/jog100`. 다른 영역 경로와 충돌하는 단어(login, map, calendar, shoesRecom, travel, inspection, profile, main, mobile)는 브랜드로 쓸 수 없고, 사용하면 "신발 없음" 상태가 된다 |

- 이 두 경로는 로그인 필요(공통 인증 가드). 새 영역 경로가 생길 때 브랜드 자리와 충돌하지 않도록 예약어 목록을 갱신해야 한다.

## 기능 목록

### SHO-01 신발 추천 목록 보기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 모바일 하단 메뉴의 "신발", 홈 하단 "더보기"의 "신발 기록" 링크(데스크톱·모바일 공통), 상세 화면의 "신발 추천으로 돌아가기". 데스크톱 상단 메뉴에는 신발 항목이 없다(홈의 "더보기" 링크로만 진입)
- **흐름**:
  1. 페이지 머리말: 현재 문구: "(서비스명)'s 신발 추천"
  2. 브랜드 이동 줄(접근성 라벨 "브랜드 이동"): "전체" + 브랜드명 목록
  3. 브랜드별 구역이 세로로 나열됨: 브랜드 로고 이미지, 브랜드명, 브랜드 한줄 소개, 그 브랜드 신발 카드 묶음
  4. 맨 아래 주의 안내문
- **표시 데이터**: 
  - 브랜드: 로고 이미지, 이름, 한줄 소개
  - 신발 카드: 대표 이미지, 브랜드명, 신발명, 한줄 소개, 가격(문자열 그대로, 예 "149,000원"), "상세 보기" 안내
  - 주의 안내문 현재 문구: "모든 신발 가격은 정가 기준이에요. 더 저렴한 다른 사이트에서 구매하는 것을 추천해요. 단, 가품이 많으니 유의해서 구매해 주세요!"
- **상태**:
  - 로딩: 없음(정적 데이터라 즉시 표시), 이미지는 지연 로딩
  - 빈 상태: 목록이 0개면 현재 문구: "아직 추천할만한 신발 정보가 없어요." (현재 데이터는 항상 있어 실제로는 표시되지 않음)
  - 에러: 없음
- **결과**: 조회 전용
- **정책·예외 규칙**: 브랜드 순서·신발 순서는 데이터에 적힌 순서(뉴발란스 → 나이키 → 아식스) 그대로. 정렬 기능 없음. 가격은 숫자가 아닌 표시 문자열이라 가격순 정렬/필터 불가.
- **데스크톱/모바일 차이**: 없음 (진입 메뉴 위치만 다름: 모바일은 하단 메뉴, 데스크톱은 홈 "더보기"). 모바일 상단 제목은 "신발 추천".

### SHO-02 브랜드로 이동 (브랜드 이동 줄)
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 목록 화면의 브랜드 이동 줄
- **흐름**: 브랜드명을 누르면 같은 페이지 안에서 해당 브랜드 구역으로 스크롤(앵커 이동)한다. "전체"를 누르면 페이지 맨 위로 부드럽게 스크롤한다.
- **상태**: "전체"가 항상 선택된 것처럼 강조되어 있고, 스크롤 위치에 따라 선택 표시가 바뀌지는 않는다(필터가 아니라 이동 링크). 목록이 비면 이 줄 자체가 숨겨진다.
- **정책·예외 규칙**: 필터가 아니므로 다른 브랜드가 숨겨지지 않는다. URL에 `#brand-{브랜드id}` 해시가 붙는다.
- **데스크톱/모바일 차이**: 없음

### SHO-03 신발 상세 보기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 목록의 신발 카드 클릭(카드 전체가 링크, 접근성 라벨 "{신발명} 상세 보기"), 또는 직접 URL
- **흐름**: 상세 화면이 열리고 다음을 위에서부터 보여준다.
  1. (데스크톱만) "신발 추천으로 돌아가기" 링크
  2. 안내 한 줄: 현재 문구: "사진을 클릭하면 구매 링크로 이동해요."
  3. 요약: 대표 이미지(가장 먼저 로드), 브랜드명, 신발명, 한줄 소개, 가격, 특징 목록(신발마다 3~4개 문장)
  4. 참고 영상 구역 (있을 때만, SHO-04)
  5. "착용 후기" 구역 (SHO-05)
- **표시 데이터**: 브랜드명, 신발명, 한줄 소개, 가격, 특징 목록(info), 대표 이미지, 참고 영상 설명/영상/영상 링크(선택), 후기 목록
- **상태**:
  - 존재하지 않는 브랜드/신발이거나 예약어 경로: 현재 문구: "찾는 신발이 없어요." + "신발 추천으로 돌아가기" 버튼(목록으로 이동)
  - 로딩/에러: 없음(정적 데이터)
- **정책·예외 규칙**: 
  - 안내 문구는 "사진을 클릭하면 구매 링크로 이동"이라고 하지만 현재 대표 이미지는 링크가 아니다(SHO 확인 필요 참고). 구매 링크 필드 자체가 데이터에 없다.
  - 현재 데이터의 신발 수: 뉴발란스(574, 530), 나이키(P-6000, V2K 런, 줌 보메로5), 아식스(조그 100) 총 6개.
- **데스크톱/모바일 차이**: "신발 추천으로 돌아가기" 링크는 데스크톱에만 있음(모바일은 기기 뒤로가기/하단 메뉴 이용). 단 "찾는 신발이 없어요." 상태의 버튼은 양쪽 모두 있음.

### SHO-04 참고 영상 보기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 신발 상세의 "참고 영상" 구역 (영상 파일 또는 영상 링크가 있는 신발만: 530, V2K 런, 줌 보메로5)
- **흐름**:
  1. 구역 제목 "참고 영상", 영상 설명(있을 때)
  2. 내장 영상(있을 때): 재생 조작부가 있고, 처음에는 대표 프레임 이미지(포스터)가 보이며 음소거·반복 재생·화면 내 재생 설정. 사용자가 직접 재생.
  3. "영상 보러가기" 버튼(링크가 있을 때): 외부 사이트(유튜브)가 새 탭에서 열림
- **표시 데이터**: 영상 설명(선택), 내장 영상 파일(선택), 영상 대표 프레임(선택), 외부 영상 링크(선택)
- **상태**: 영상 파일도 링크도 없으면 구역 전체가 나타나지 않음. 설명이 없으면 설명 줄 생략.
- **정책·예외 규칙**: 530은 외부 링크만(설명 있음), V2K 런/줌 보메로5는 내장 영상+외부 링크(설명 없음, 현재 두 신발의 외부 링크가 같은 주소). 내장 영상은 메타데이터만 미리 불러옴(`preload=metadata`).
- **데스크톱/모바일 차이**: 없음

### SHO-05 착용 후기 보기 및 외부 이동
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 신발 상세 하단 "착용 후기"
- **흐름**: 신발마다 2개의 후기 항목이 나열된다. 각 항목은 이미지 + 한 줄 설명 캡션이며, 항목을 누르면 원문 게시물(블로그·인스타그램·유튜브·중고/커머스 커뮤니티 등)이 새 탭에서 열린다.
- **표시 데이터**: 후기 이미지(외부 이미지 주소 또는 앱 내장 이미지), 한 줄 설명(예: "아이유도 신는 그 신발,,,"), 연결 링크
- **상태**: 후기가 0개면 제목만 있고 목록이 비어 보임(별도 빈 문구 없음; 현재 데이터는 항상 2개)
- **정책·예외 규칙**: 외부 이미지가 로드 실패하면 이미지 대체 텍스트(후기 설명)가 보인다. 링크는 새 탭 + opener 차단.
- **데스크톱/모바일 차이**: 없음

## 데이터 필드 사전

브랜드:

| 필드 | 의미 | 형식/예시 | 비어 있을 수 있는지 |
|---|---|---|---|
| id | 브랜드 순번 | 숫자 | 아니오 |
| brandId | URL에 쓰이는 브랜드 식별 문자열 | `nb`, `nike`, `asics` (영문 소문자) | 아니오, 유일해야 함, 예약어 불가 |
| name | 브랜드 표시명 | 뉴발란스 / 나이키 / 아식스 | 아니오 |
| desc | 브랜드 한줄 소개 | 구어체 문장 | 아니오 |
| imageUrl | 브랜드 로고 이미지 | 앱 내장 이미지 | 아니오 |
| shoes | 소속 신발 목록 | 배열 | 아니오 |

신발:

| 필드 | 의미 | 형식/예시 | 비어 있을 수 있는지 |
|---|---|---|---|
| id | 브랜드 안 순번 | 숫자 | 아니오 |
| shoesId | URL에 쓰이는 신발 식별 문자열 | `nb574`, `v2k`, `zoombomero5` | 아니오, 브랜드 안에서 유일 |
| name | 신발명 | "뉴발란스 574" | 아니오 |
| desc | 한줄 소개 | 문장 | 아니오 |
| price | 표시용 가격 문자열 | "149,000원" (정가 기준, 숫자 아님) | 아니오 |
| imageUrl | 대표 이미지 | 앱 내장 이미지 | 아니오 |
| info | 특징 문장 목록 | 문자열 배열 (3~4개, 이모지 포함 가능) | 아니오(최소 1개 기대) |
| videoLink | 외부 영상 주소 | URL 또는 없음 | 예 |
| videoUrl | 내장 영상 파일 | 파일 경로 또는 없음 | 예 |
| videoPosterUrl | 내장 영상 대표 프레임 | 이미지 또는 없음 | 예 (videoUrl이 있을 때 함께 제공됨) |
| videoDesc | 영상 설명 | 문장 또는 없음 | 예 |
| reviews | 착용 후기 목록 | 배열 | 아니오 |

후기:

| 필드 | 의미 | 형식/예시 | 비어 있을 수 있는지 |
|---|---|---|---|
| imageUrl | 후기 이미지 | 외부 URL 또는 내장 이미지 | 아니오 |
| description | 한 줄 캡션(이미지 대체 텍스트 겸용) | 문장 | 아니오 |
| linkUrl | 원문 게시물 주소 | 외부 URL | 아니오 |

## 기술 제약
- 데이터는 서버 API가 아니라 앱 소스에 정적으로 들어 있다. 신발·브랜드를 추가/수정/삭제하려면 앱을 다시 배포해야 하며, 사용자가 화면에서 편집할 수 없다. 로딩·에러 상태가 발생하지 않는다.
- 필터·정렬·검색을 넣으려면 데이터에 가격 숫자값, 카테고리 등 새 필드가 필요하다(현재 가격은 문자열 표시값뿐).
- 후기 이미지 일부는 외부 사이트(네이버 블로그 썸네일, CDN 등) 이미지 주소를 직접 사용한다. 원 사이트 정책으로 이미지가 깨지거나 사라질 수 있다.
- 후기·영상 링크는 외부 사이트(인스타그램, 네이버 블로그, 유튜브, 커뮤니티)이며 앱 밖에서 열려야 한다(새 탭). 외부 사이트의 로그인 요구 등은 통제할 수 없다.
- 내장 영상은 mp4 파일로, 첫 프레임 이미지(포스터)와 함께 쓰이며 자동 재생하지 않고 음소거 상태로 시작한다(브라우저 자동재생 정책 및 데이터 사용량 고려).
- 상세 경로(`:brand/:shoesName`)는 최상위에 가까운 와일드카드 형태라 다른 영역 경로와 충돌하지 않도록 예약어 목록을 유지해야 한다.
- 브랜드 앵커 이동은 페이지 내 해시(`#brand-{brandId}`)에 의존한다.

## 확인 필요
- 상세 화면 안내 문구 "사진을 클릭하면 구매 링크로 이동해요."와 달리 대표 이미지에 링크가 없고, 데이터에도 구매 링크 필드가 없다. 구매 링크가 미구현(죽은 안내)인지 기획 확인 필요.
- 목록 머리말에 서비스명이 포함된 문구가 쓰이며 이 문서에서는 "(서비스명)"으로 대체했다. 리디자인 시 문구 정책 확인.
- 브랜드 이동 줄의 "전체"가 항상 강조 상태로 고정되어 있고 스크롤에 따라 현재 브랜드가 표시되지 않는다. 의도된 것인지 확인.
- 데스크톱 상단 메뉴에 신발 항목이 없고 홈 "더보기"의 "신발 기록" 링크로만 접근 가능(링크 문구는 "신발 기록", 화면 제목은 "신발 추천"으로 용어 불일치). 의도 확인.
- 필터/정렬 기능은 없음(요청 범위에 포함되었으나 코드에 없음).
- 줌 보메로5·V2K 런의 외부 영상 링크가 동일 주소로 보임(데이터 오류 가능).
- 로그인 필요 여부: 일반 보호 경로로 등록되어 있어 로그인 필요로 기술함. 비로그인 공개 정책이 있는지는 별도 확인 필요.
