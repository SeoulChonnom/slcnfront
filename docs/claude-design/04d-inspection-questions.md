# 임장 — 체크리스트 질문 관리(관리자)

> 상위 문서: [04-inspection.md](./04-inspection.md) (개요·URL·데이터 필드 사전·기술 제약·확인 필요). 이 파일의 기능 ID는 전체 임장 영역에서 유일하다.

## 기능 목록
### INS-80 질문 목록 보기 (관리자)
- **대상 사용자**: 관리자만
- **진입 경로**: 지역 목록의 "질문 관리"
- **흐름**:
  1. 제목 "질문 관리", 설명 현재 문구: "매물마다 묻는 질문입니다. 여기서 바꾼 내용은 앞으로 만드는 매물부터 적용되고, 이미 저장된 답변은 그대로 남습니다. 질문은 분류별로 묶여 매물 문답 화면에 이 순서대로 나옵니다."
  2. 사용 중인 분류가 순서대로 구역으로 나뉘고, 구역 머리에 분류명(누르면 접기/펼치기)과 요약 "질문 {n} · 필수 {m} · 미사용 {k}"(0은 생략)을 보인다. 분류가 2개 이상이면 "모두 접기"/"모두 펼치기".
  3. 질문 한 줄: 질문 문구, "v{현재 버전} · 답변 {n}건"(답변 수가 없으면 "—") + 선택형이면 " · 보기 {n}개: A / B", 버전 기록 토글(INS-85), 유형 표시(한 줄 글, 긴 글, 숫자, 예 / 아니오, 단일 선택, 다중 선택, 별점), 필수/선택, 사용 여부 스위치("사용중"/"미사용", INS-83), "수정"(INS-82). 미사용 질문도 목록에 남아 구분되게 표시.
  4. 사용하지 않는 분류는 "미사용 분류 {n}개"(매물 문답에 나오지 않습니다) 접이식 영역 안에서 같은 형태로 본다.
- **상태**:
  - 로딩: 질문 줄 모양 자리표시.
  - 에러: 현재 문구: "질문 목록을 불러오지 못했습니다" / "네트워크 상태를 확인한 뒤 다시 시도해 주세요." + 다시 시도(질문·분류 둘 다 재조회).
  - 분류가 하나도 없음: 현재 문구: "질문은 분류 안에 만듭니다. 먼저 '채광·환기'처럼 묶을 분류를 하나 만들어 주세요." + "+ 분류 추가".
  - 분류에 질문 없음: 현재 문구: 사용 중 분류 "아직 이 분류에 질문이 없습니다.", 미사용 분류 "이 분류에는 질문이 없습니다."
  - 편집 중 상호 배타: 질문 순서 변경·분류 순서 변경·분류 추가 중 하나가 진행 중이면 다른 구역의 편집 동작은 비활성(한 번에 하나).
- **결과**: 없음(조회)
- **정책·예외 규칙**: 질문 삭제 기능은 없다. 제거는 "미사용 처리"뿐이다. 모든 질문은 정확히 한 분류에 속한다.
- **데스크톱/모바일 차이**: 없음 (모바일은 열 구성만 좁게)
### INS-81 질문 추가
- **대상 사용자**: 관리자만
- **진입 경로**: 헤더의 "+ 질문 추가"(사용 중 분류가 하나 이상일 때만 활성; 첫 분류가 기본 선택), 또는 분류 구역 하단의 "{분류명}에 질문 추가"(그 분류가 기본 선택)
- **흐름**: 화면 이동 없는 입력 단계(제목 "질문 추가")에서 입력 후 "질문 추가"를 누르면 분류 맨 뒤에 만들어진다.
- **입력 항목**:
  | 항목 | 형식 | 필수 | 제약·검증 | 현재 에러 문구 |
  |---|---|---|---|---|
  | 분류 | 선택(사용 중 분류만) | 예 | 선택된 분류가 없으면 저장 불가 | 현재 문구: "질문을 넣을 분류를 골라 주세요." |
  | 질문 | 텍스트 | 예 | 공백뿐이면 불가 | 현재 문구: "질문 문장을 입력해 주세요." |
  | 설명 | 텍스트 | 아니오 | 안내 "매물 문답 화면에서 질문 아래에 작게 표시됩니다." | 없음 |
  | 타입 | 선택: 한 줄 글, 긴 글, 숫자, 예 / 아니오, 단일 선택, 다중 선택, 별점 | 예(기본 한 줄 글) | **생성 시에만 선택 가능** | 없음 |
  | 필수 여부 | 필수/선택 | 예(기본 필수) | | 없음 |
  | 단위 | 텍스트 | 아니오 | 숫자 타입일 때만 표시. 안내 "숫자 답변 뒤에 붙는 단위입니다. 예: 대, 만원" | 없음 |
  | 선택지 | 코드+보기 문구 목록 | 선택형일 때 필수 | 최소 1개(마지막 1개는 삭제 불가), 코드·문구 모두 입력, 코드는 질문 안에서 서로 달라야 함. 안내 "최소 1개, 코드는 이 질문 안에서 서로 달라야 합니다." "+ 선택지 추가" | 현재 문구: "선택지를 최소 1개 입력해 주세요." / "모든 선택지에 코드를 입력해 주세요." / "모든 선택지에 문구를 입력해 주세요." / "선택지 코드는 이 질문 안에서 서로 달라야 합니다." |
- **상태**: 처리 중 버튼 로딩. 서버 거절은 코드별 문구(INS-82 목록) 또는 현재 문구: "저장 중 문제가 생겼습니다. 다시 시도해 주세요." (충돌 계열: "질문이 이미 수정되었습니다. 새로고침 후 다시 시도하세요.")
- **결과**: 닫히고 목록 갱신. 새 질문은 선택한 분류의 맨 뒤.
- **데스크톱/모바일 차이**: 없음
### INS-82 질문 수정
- **대상 사용자**: 관리자만
- **진입 경로**: 질문 줄의 "수정"
- **흐름**:
  1. 입력 단계 제목 "질문 수정", 설명 현재 문구: "현재 v{n} · 답변 {m}건이 이 질문을 참조하고 있습니다."
  2. 수정 가능: 분류(미사용으로 바뀐 현재 분류도 목록에 "(미사용)"으로 보임, 사용 중 분류만 선택 가능), 질문 문구, 설명, 선택지, 단위, 필수 여부. **타입은 수정 불가**(비활성, 현재 문구: "답변이 있는 질문은 타입을 바꿀 수 없습니다.").
  3. 분류를 바꾸면 안내 현재 문구: "저장하면 '{분류}' 분류의 맨 뒤로 옮겨집니다. 옮겨도 버전은 바뀌지 않고, 이미 저장된 매물의 분류 표시도 그대로입니다."
  4. 질문 문구·설명·선택지·단위 중 하나라도 바뀌면 **새 버전이 만들어진다**: 안내 현재 문구: "질문 문장을 고치면 v{n+1}이 새로 생깁니다. 이미 저장된 답변 {m}건은 각자 답할 때의 문장(v1·v2…)을 그대로 보여 줍니다." 저장 버튼 문구는 "v{n+1}으로 저장". 문구 변경이 없으면 "저장". 필수 여부·분류만 바뀌면 버전은 유지.
  5. 변경이 없으면 저장 버튼 비활성.
  6. 하단 왼쪽에 "미사용 처리"/"사용 처리"(INS-83의 단축 경로, 누르면 즉시 처리 후 닫힘).
- **상태**: 저장은 문구 → 필수 → 분류 순서로 차례로 요청하며 중간에 실패하면 거기서 멈추고 오류 표시, 이미 반영된 변경은 남는다. 오류 현재 문구(코드별, 질문·분류 관리 공통):
  - 같은 이름 분류 중복: "같은 이름의 분류가 이미 있습니다. 미사용 분류까지 포함해 이름이 겹치면 안 됩니다."
  - 분류 이름 길이: "분류 이름은 1~50자로 입력해 주세요."
  - 분류에 사용 중 질문이 남음: "사용 중인 질문이 남아 있어 미사용 처리할 수 없습니다. 질문을 먼저 미사용 처리하거나 다른 분류로 옮겨 주세요."
  - 분류 동시 수정: "다른 곳에서 먼저 수정했습니다. 새로고침 후 다시 시도하세요."
  - 분류 미선택: "질문을 넣을 분류를 골라 주세요."
  - 분류 없음: "선택한 분류를 찾을 수 없습니다. 새로고침 후 다른 분류를 골라 주세요."
  - 미사용 분류에 넣기: "미사용 분류에는 질문을 넣을 수 없습니다. 다른 분류를 골라 주세요."
  - 미사용 분류의 질문 재사용: "미사용 분류에 있는 질문은 다시 사용할 수 없습니다. 분류를 먼저 다시 사용하거나 다른 분류로 옮겨 주세요."
  - 질문 동시 수정: "질문이 이미 수정되었습니다. 새로고침 후 다시 시도하세요."
  - 그 밖: "저장 중 문제가 생겼습니다. 다시 시도해 주세요."
- **결과**: 닫히고 목록 갱신. 기존 매물의 저장된 답변과 질문 문구는 변하지 않음.
- **정책·예외 규칙**: 필수 여부만 바꿔도 질문 순서가 앞으로 밀리지 않도록 현재 순서값을 함께 보낸다. 분류 이동 시 새 분류의 맨 뒤로 번호가 새로 매겨진다.
- **데스크톱/모바일 차이**: 없음
### INS-83 질문 사용/미사용 전환
- **대상 사용자**: 관리자만
- **진입 경로**: 질문 줄의 사용 여부 스위치(접근성 이름 "{질문} 사용 여부") 또는 수정 화면의 "미사용 처리/사용 처리"
- **흐름**: 누르면 즉시 전환된다(확인 절차 없음). 스위치 옆에 "사용중"/"미사용". 처리 중에는 스위치 비활성.
- **상태**: 실패 시 줄 아래 오류. 코드별 문구는 INS-82 목록(특히 미사용 분류에 있는 질문 재사용 불가), 그 밖: 충돌 "질문이 이미 수정되었습니다. 새로고침 후 다시 시도하세요.", 일반 "변경하지 못했습니다. 다시 시도해 주세요."
- **결과**: 새로 만드는 매물부터 반영. 기존 매물에는 "비활성 질문" 배지로만 표시.
- **데스크톱/모바일 차이**: 없음
### INS-84 질문 순서 변경 (분류 안)
- **대상 사용자**: 관리자만
- **진입 경로**: 분류 머리의 "순서 변경" (사용 중 분류에 질문이 2개 이상일 때만 표시)
- **흐름**:
  1. 누르면 그 분류가 순서 변경 모드가 되고(다른 구역 동작은 잠김, 접혀 있어도 펼쳐짐) 안내 현재 문구: "끌어서 옮기거나 위·아래 버튼으로 순서를 바꾸세요. 다른 분류로 옮기려면 질문의 [수정]에서 분류를 바꿉니다."
  2. 줄을 끌어 놓거나 줄마다 "{질문} 위로 이동"/"아래로 이동"(↑↓, 양 끝은 비활성)으로 옮긴다. 이 모드에서는 유형·필수·스위치·수정이 숨겨진다.
  3. "순서 저장" 또는 "취소".
- **상태**: 처리 중 저장 버튼 로딩. 실패 현재 문구: 충돌 "순서를 저장하지 못했습니다. 새로고침 후 다시 시도하세요.", 그 밖 "순서를 저장하지 못했습니다. 다시 시도해 주세요."
- **결과**: 분류 안 질문 순서가 1부터 다시 매겨져 저장되고, 이후 매물 문답 화면에 그 순서로 나타난다.
- **정책·예외 규칙**: 순서는 분류 안에서만 바꾼다(분류 이동은 INS-82).
- **데스크톱/모바일 차이**: 없음
### INS-85 질문 버전 기록 보기
- **대상 사용자**: 관리자만
- **진입 경로**: 질문 줄의 "버전 기록 보기"/"버전 기록 숨기기"
- **흐름**: 펼칠 때 비로소 버전 목록을 불러온다. 각 버전: "v{n}", 그 당시 질문 문구, "날짜 미상 · 답변 {n}건".
- **상태**: 로딩 자리표시. 실패 현재 문구: "버전 기록을 불러오지 못했습니다."
- **정책·예외 규칙**: 버전에는 생성 일시 정보가 없어 날짜를 표시하지 않는다(항상 "날짜 미상").
- **데스크톱/모바일 차이**: 없음
### INS-86 분류 추가
- **대상 사용자**: 관리자만
- **진입 경로**: 헤더의 "+ 분류 추가", 분류가 없을 때의 안내 속 "+ 분류 추가"
- **흐름**: 목록 끝에 "새 분류" 입력이 열린다(안내 "예: 채광·환기", 1~50자, 열리면 초점, Esc로 닫기). "분류 만들기"로 생성하면 분류 목록 맨 뒤에 추가된다. 안내 현재 문구: "목록 맨 뒤에 추가됩니다. 이름은 나중에 바꿀 수 있지만 분류를 지울 수는 없고, 미사용 처리만 할 수 있습니다."
- **입력 항목**:
  | 항목 | 형식 | 필수 | 제약·검증 | 현재 에러 문구 |
  |---|---|---|---|---|
  | 분류 이름 | 텍스트 | 예 | 공백 제거 후 1~50자 | 현재 문구: "분류 이름은 1~50자로 입력해 주세요." |
  | (중복) | | | 같은 이름의 **사용 중** 분류가 이미 있으면 불가 | 현재 문구: "'{이름}' 분류가 이미 있습니다." |
- **상태**:
  - 같은 이름이 **미사용 분류**에 있으면 새로 만들지 않고 되살릴지 묻는다: 현재 문구: "미사용 분류 중에 '{이름}'이 있습니다. 새로 만들지 않고 그 분류를 다시 사용할까요?" + "'{이름}' 다시 사용".
  - 서버 거절: 코드별 문구(INS-82 목록) 또는 "분류를 만들지 못했습니다. 다시 시도해 주세요." / 되살리기 실패 "다시 사용하지 못했습니다. 다시 시도해 주세요."
  - 다른 편집이 진행 중이면 "+ 분류 추가"는 비활성(목록 로딩·에러 중에도 비활성).
- **결과**: 새 분류 구역이 목록 맨 뒤에 나타난다.
- **데스크톱/모바일 차이**: 없음
### INS-87 분류 이름 변경
- **대상 사용자**: 관리자만
- **진입 경로**: 분류 머리의 "이름 변경"
- **흐름**: 제목 자리에 이름 입력이 열린다(Esc로 취소). "이름 저장"/"취소". 이미 저장된 매물의 분류 표시는 바뀌지 않는다.
- **입력 항목**: 분류 이름 — 1~50자.
- **상태**: 현재 문구: 길이 오류 "분류 이름은 1~50자로 입력해 주세요.", 사용 중 분류와 중복 "'{이름}' 분류가 이미 있습니다.", 미사용 분류와 중복 "미사용 분류 중에 '{이름}'이 이미 있습니다. 분류 이름은 미사용 분류와도 겹칠 수 없습니다.", 그 밖 서버 거절 코드별 문구 또는 "이름을 바꾸지 못했습니다." 이름이 변하지 않았으면 그냥 닫힘.
- **결과**: 목록 갱신
- **데스크톱/모바일 차이**: 없음
### INS-88 분류 미사용 처리 / 다시 사용
- **대상 사용자**: 관리자만
- **진입 경로**: 분류 머리의 "미사용 처리" / (미사용 분류에서) "다시 사용"
- **흐름**: 누르면 즉시 전환된다(확인 절차 없음). 사용 중 질문이 남은 분류는 요청하지 않고 안내만 표시한다: 현재 문구: "사용 중인 질문 {n}개를 먼저 미사용 처리하거나 다른 분류로 옮겨야 분류를 내릴 수 있습니다."
- **상태**: 서버 거절 시 코드별 문구 또는 "변경하지 못했습니다. 다시 시도해 주세요."
- **결과**: 미사용 분류는 "미사용 분류 {n}개" 접이식 영역으로 이동하고 매물 문답에 나타나지 않는다. 분류 삭제는 불가.
- **데스크톱/모바일 차이**: 없음
### INS-89 분류 순서 변경
- **대상 사용자**: 관리자만
- **진입 경로**: 헤더의 "분류 순서 변경" (사용 중 분류가 2개 이상일 때만 활성, 다른 편집 중에는 비활성)
- **흐름**: 질문 줄을 숨기고 분류 이름 목록만 보인다(순번, 이름, "질문 {n}", "{분류} 위로 이동"/"아래로 이동" 버튼, 양 끝 비활성). 안내 현재 문구: "위에 있는 분류부터 매물 문답 화면에 나옵니다. 미사용 분류는 순서에 포함되지 않습니다." 헤더 버튼은 "취소"/"분류 순서 저장"으로 바뀐다.
- **상태**: 실패 현재 문구: 충돌 "순서를 저장하지 못했습니다. 새로고침 후 다시 시도하세요.", 그 밖 "순서를 저장하지 못했습니다. 다시 시도해 주세요." 저장 중 취소 비활성.
- **결과**: 순서(1부터)가 저장되고 매물 문답 화면의 분류 순서에 반영
- **데스크톱/모바일 차이**: 없음
