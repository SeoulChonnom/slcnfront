# 홈

## 개요
로그인 직후 도착하는 첫 화면으로, 지난 여행 기록을 최신순으로 훑어보고(가장 최근 여행 1건을 크게, 나머지는 목록) 제목·지역·한 줄 기록 검색과 연도 필터로 찾을 수 있다. 같은 화면에서 다가오는 일정 최대 3건과 나들이 기록 개수를 요약해 보여주고, 여행 등록·달력·나들이·신발·외부 링크로 이동하는 진입점을 제공한다. 데스크톱과 모바일이 같은 기능을 갖는다.

## URL
| 경로 (/main, /mobile 공통 뒤쪽) | 화면 의미 | 접근 권한 | 비고 |
|---|---|---|---|
| (빈 경로) → `/main`, `/mobile` | 홈 | 로그인 | 로그인 후 기본 도착지. 모바일 하단 내비 "홈" 활성 |

## 기능 목록

### HOME-01 홈 첫 진입 (요약 데이터 불러오기)
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 로그인 성공 후 기본 도착지, 데스크톱 헤더 로고/"홈", 모바일 하단 내비 "홈", 404 의 "홈으로 돌아가기", 상세형 화면의 뒤로가기(일부)
- **흐름**: 1. 화면 진입 시 여행 목록·현재 일정·나들이 목록 세 가지를 **서로 독립적으로** 병렬 조회 2. 각 영역이 자기 데이터가 준비되는 대로 표시 3. 상단에 제목 "지난 여행"과 함께 "만난 지 N일째" 표시
- **표시 데이터**: 화면 제목 현재 문구: "지난 여행". 일수 표시 현재 문구: "만난 지 {N}일째" — N 은 고정 기준일(2024-11-10, 한국 시간)부터 오늘까지의 일수에 1을 더한 값(기준일 당일 = 1일째). 사용자별 설정이 아닌 하드코딩된 값.
- **상태**:
  - 세 데이터가 **모두** 실패 — 전체 오류 영역: 제목 현재 문구 "여행 기록을 불러오지 못했어요." / 설명 "잠시 후 다시 시도해 주세요." / "다시 시도"(세 데이터 모두 재요청). 이때 여행 영역·검색·다음 일정·나들이 영역은 모두 숨김(제목과 "더보기"만 남음).
  - 일부만 실패 — 해당 영역에만 개별 오류와 "다시 시도"(HOME-02~05 참조), 나머지는 정상 표시.
- **결과**: 없음(조회 화면)
- **정책·예외 규칙**: 새로고침/재진입 시 30초 이내면 캐시된 데이터를 재사용. 창 포커스 복귀로는 자동 갱신하지 않음.
- **데스크톱/모바일 차이**: 없음 (링크가 기기별 경로로 연결될 뿐)

### HOME-02 가장 최근 여행 보기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 홈 상단 대표 영역
- **흐름**: 1. 시작일 기준 가장 최근 여행(같은 날짜면 ID 순) 1건을 대표로 표시 2. 대표 영역 전체를 눌러 해당 여행 상세(`/travel/:id`)로 이동. 보조 기술용 이름: "{여행 제목} 여행 상세 보기"
- **표시 데이터**: 표지 사진(있으면, 큰 크기 변형), 기간 라벨(dateRangeLabel), 지역, 박/일 라벨(nightsDaysLabel), 여행 제목, 한 줄 기록(있을 때만), 동작 라벨 현재 문구 "여행 기록 열기"
- **상태**:
  - 로딩 — 여행 로딩 표시(아래 HOME-03 로딩과 동일 표시, 상태 알림 이름 "여행 기록을 불러오는 중")
  - 표지 사진 없음 — 사진 자리에 "사진 없이 남긴 여행"과 여행 제목을 표시(보조 이름 "표지 사진 없음")
  - 여행 0건 — 빈 상태: 제목 현재 문구 "아직 남긴 여행이 없어요." / 설명 "같이 다녀온 여행을 기록해 두면 다시 꺼내 볼 수 있어요." / 이동 "첫 여행 기록하기"(→ `/travel/register`)
  - 여행 조회만 실패(나머지는 성공) — "여행 기록을 불러오지 못했어요." + "다시 시도"(알림 역할). 이때 대표/검색/목록 영역은 표시되지 않음.
- **결과**: 여행 상세 화면으로 이동
- **정책·예외 규칙**: **검색·연도 필터는 대표 여행에 적용되지 않는다**(항상 전체 중 최신 1건). 대표 여행은 아래 목록(HOME-03)에서 제외된다.
- **데스크톱/모바일 차이**: 없음

### HOME-03 지난 여행 기록 목록 보기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 홈 중단 "여행 기록 찾기" 영역
- **흐름**: 1. 대표 여행을 제외한 여행을 시작일 최신순(같은 날짜면 ID 순)으로 나열 2. 한 건을 누르면 해당 여행 상세(`/travel/:id`)로 이동(보조 이름 "{여행 제목} 여행 보기")
- **표시 데이터**: 시작 날짜 표시(displayStartDate), 제목, 지역 · 박/일 라벨, 한 줄 기록(있을 때만), 표지 사진 작은 크기(있을 때만; 없으면 사진 없이 표시)
- **상태**:
  - 필터 없음 + 대표 외 여행이 없음 — 현재 문구 "더 오래된 여행은 아직 없어요."
  - 필터 있음 + 결과 0건(필터와 일치하는 여행이 하나도 없음) — 현재 문구 "검색 결과가 없어요" + "검색 초기화" 버튼(검색어·연도 모두 해제)
  - 필터 있음 + 일치 여행이 대표 한 건뿐(목록은 비고 일치는 존재) — 현재 문구 "가장 최근 여행이 검색 결과예요." (초기화 버튼 없음)
  - 이미지 — 화면에 가까워질 때 지연 로드
- **결과**: 여행 상세 화면으로 이동
- **정책·예외 규칙**: 페이지네이션·무한 스크롤 없이 불러온 전체를 한 번에 나열.
- **데스크톱/모바일 차이**: 없음

### HOME-04 여행 기록 검색 및 연도 필터
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: "여행 기록 찾기" 영역
- **흐름**: 1. 검색 입력(접근성 이름 "여행 기록 검색", 자리표시 "제목 · 지역 · 한 줄 기록")에 입력하면 입력 즉시(버튼 없이) 목록이 걸러짐 2. 연도 선택 줄(접근성 이름 "여행 연도")에서 "전체" 또는 "{연도}년" 하나를 선택하면 그 해 시작한 여행만 표시(선택 상태 표시, 하나만 선택 가능) 3. 검색어가 있을 때 나타나는 "초기화"(접근성 이름 "검색 초기화")로 검색어만 비움 4. 검색과 연도는 AND 로 함께 적용
- **입력 항목**:

| 항목 | 형식 | 필수 | 제약·검증 | 현재 에러 문구 |
|---|---|---|---|---|
| 여행 기록 검색 | 텍스트(검색 입력) | 아니오 | 앞뒤 공백 무시, 대소문자 무시, 부분 일치. 대상 필드: 제목·지역·한 줄 기록 | 없음 |
| 연도 선택 | 단일 선택 | 아니오(기본 "전체") | 선택지는 불러온 여행의 시작 연도(4자리 숫자)를 최신 연도부터 중복 없이 나열 | 없음 |

- **표시 데이터**: 연도 선택지 목록, 현재 검색어
- **상태**: 결과 상태는 HOME-03 상태 참조. 여행이 하나도 없어도 검색·연도 영역은 표시된다(연도 선택지는 "전체"만).
- **정책·예외 규칙**: 서버 검색이 아닌 이미 불러온 데이터에 대한 화면 내 필터링이다(대소문자 구분 없음은 로마자에만 의미). 필터 상태는 URL 에 저장되지 않아 새로고침/이동 후 사라진다. 연도는 시작일 기준.
- **데스크톱/모바일 차이**: 없음

### HOME-05 다음 일정 확인
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 홈 "다음 일정" 영역
- **흐름**: 1. 현재 시점 이후의 일정 중 날짜가 가장 가까운 최대 3건 표시 2. 일정 한 건을 누르면 **달력(월) 화면**(`/calendar`)으로 이동(해당 일정 자체로 이동하거나 해당 월로 이동하지는 않음; 보조 이름 "{일정 제목} 일정 보기") 3. 영역 제목 옆 "달력 보기"로도 같은 달력으로 이동
- **표시 데이터**: 시간 표기 — 종일 일정은 "하루 종일", 시간 일정은 "HH:mm", 시간을 알 수 없으면 "일정"; 일정 제목; 장소(있을 때만)
- **상태**:
  - 로딩 — 현재 문구 "일정을 불러오는 중"(상태 알림)
  - 오류 — "일정 정보를 불러오지 못했어요." + "다시 시도"(알림 역할)
  - 빈 상태 — 현재 문구 "아직 예정된 일정이 없어요." + 링크 "달력에서 계획하기"(→ 달력)
- **정책·예외 규칙**: 정렬 — 날짜(현지 기준) 오름차순, 같은 날은 종일 일정이 시간 일정보다 먼저, 시간 일정은 시작 시각 순. 오늘 종일 일정은 포함, 이미 시작한 시간 일정은 제외, 시작 시각이 잘못된 일정은 제외.
- **데스크톱/모바일 차이**: 없음

### HOME-06 나들이 기록 요약과 이동
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 홈 "나들이" 영역
- **흐름**: 영역 제목 옆 링크 "나들이 기록으로 가기" → 나들이 목록(`/map`)
- **표시 데이터**: 나들이 개수 요약만 표시 (개별 나들이 정보는 표시하지 않음). 현재 문구 "남긴 나들이 {N}개"
- **상태**: 로딩 "나들이 기록을 불러오는 중"(상태 알림) / 오류 "나들이 기록을 불러오지 못했어요." + "다시 시도" / 빈 상태 "아직 남긴 나들이가 없어요."
- **데스크톱/모바일 차이**: 없음

### HOME-07 더보기 링크
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 홈 하단 "더보기" 영역(접근성 이름 "더보기")
- **기능**: "신발 기록" → 신발 목록(`/shoesRecom`) / "Choi's Film Art" → 외부 사이트(새 탭, `http://naver.me/52RjLNuT`)
- **정책·예외 규칙**: 데스크톱 헤더에는 신발 메뉴가 없으므로 데스크톱에서 신발 목록으로 가는 주 진입점이다. 데스크톱 푸터의 같은 외부 링크는 홈에서 숨겨진다(COM-10). 이 영역은 전체 오류 상태에서도 남는다.
- **데스크톱/모바일 차이**: 모바일은 하단 내비에 "신발"이 있으나 홈에서는 숨겨지므로(COM-11) 모바일에서도 홈에서는 이 링크가 신발 진입점이다.

### HOME-08 새 여행 기록으로 이동 (빈 상태 진입점)
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 여행이 0건일 때만 보이는 "첫 여행 기록하기" (HOME-02)
- **결과**: `/travel/register`
- **정책·예외 규칙**: 여행이 1건 이상이면 홈에는 새 여행 등록 직접 진입점이 없다(여행 목록 화면에서 진행).
- **데스크톱/모바일 차이**: 없음

## 데이터 필드 사전
| 필드 | 의미 | 형식/예시 | 비어 있을 수 있는지 |
|---|---|---|---|
| 여행 ID(travelId) | 여행 식별 | 문자열 | 아니오 |
| 제목(title) | 여행 제목 | 문자열 | 아니오 |
| 지역(region) | 여행 지역 | 문자열 | 아니오(목록에서 항상 표시) |
| 시작일(startDate) | 정렬·연도 필터 기준 | 날짜 문자열 (숫자만 비교) | 아니오 |
| 시작 날짜 표시(displayStartDate) | 목록 행의 날짜 표기 | 문자열 | 아니오 |
| 기간 라벨(dateRangeLabel) | 대표 영역의 기간 표기 | 문자열 | 아니오 |
| 박/일 라벨(nightsDaysLabel) | 예: 2박 3일 형태 | 문자열 | 아니오 |
| 한 줄 기록(oneLineReview) | 여행 한 줄 소감 | 문자열 | 예 |
| 표지 사진(coverPhotoId) | 대표/목록 이미지 | 파일 ID | 예 |
| 일정 제목 / 장소 | 다음 일정 표시 | 문자열 | 장소는 예 |
| 일정 시작(start) / 종일 여부(allDay) | 정렬·시간 표기 | ISO 날짜/시각, 불리언 | 아니오 |
| 나들이 개수 | 나들이 목록 길이 | 정수 | 0 가능 |
| 만난 지 N일째 | 기준일(2024-11-10) 경과 일수+1 | 정수 | 아니오 |

## 기술 제약
- 홈은 세 개의 목록 조회 결과(여행 전체, 현재 시점 일정, 나들이 전체)에 의존하며 서버 페이지네이션/검색을 쓰지 않는다. 여행/나들이가 많아져도 전체를 불러와 화면에서 걸러낸다.
- 일정은 서버가 "현재 일정" 집합으로 돌려준 것 중 화면에서 다시 시각 비교해 3건을 고른다.
- 표지 사진은 서버의 크기 변형(대표용 큼/목록용 작음)만 사용 가능.
- 기준일 "2024-11-10"은 코드에 고정된 값이다.
- 검색어·연도 필터는 URL/저장소에 보관하지 않는다.

## 확인 필요
- 홈이 부분 실패 상태를 계산하는 값(일부 실패 여부)은 있으나 별도 표시에 쓰이지 않고, 영역별 개별 오류만 표시됨.
- 일정을 눌렀을 때 해당 날짜·일정이 아닌 달력(월) 기본 화면으로만 이동하는 것이 의도인지 확인 필요.
- "만난 지 N일째" 기준일이 고정값인 것이 의도인지(개인 기념일 성격) 확인 필요.
- 홈에서 여행이 1건 이상일 때 "새 여행 기록" 진입점이 없는 점이 의도인지 확인 필요.
- 대표 여행이 검색에 영향받지 않는 점이 의도인지 확인 필요(검색해도 대표 영역은 그대로 남음).
