# 임장 — 지역 목록·지역 상세·회차(방문)

> 상위 문서: [04-inspection.md](./04-inspection.md) (개요·URL·데이터 필드 사전·기술 제약·확인 필요). 이 파일의 기능 ID는 전체 임장 영역에서 유일하다.

## 기능 목록
### INS-01 지역 목록 보기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 메뉴의 "임장", 또는 다른 임장 화면의 상위 경로 링크
- **흐름**:
  1. 진입하면 현재 검색어·필터·정렬 조건으로 지역 목록을 불러온다.
  2. 화면 상단에 제목 "임장"과 전체 요약 한 줄을 보인다. 현재 문구: "{N}개 지역을 {M}번 걸었고, 매물 {K}건을 봤습니다." (데이터가 로드된 뒤에만 표시)
  3. 지역 한 건을 누르면 해당 지역 상세(INS-10)로 이동한다(행 전체가 이동 대상).
- **표시 데이터** (지역 한 건):
  - 지역명, 지역 설명(있을 때만)
  - 가장 최근 회차의 상태 배지(INS-07; 완료면 배지 없음)
  - 방문 횟수("N회")와 횟수만큼의 방문 표시, 마지막 방문일("최근 MM.DD")
  - 가장 최근 회차의 한줄평(따옴표로 감쌈). 없으면 현재 문구: "한줄평을 아직 쓰지 않았습니다."
  - 가장 최근 회차의 태그(최대 3개, 초과분은 "+N"), 재방문 의사 표시(INS-08)
  - "최근 임장 yyyy.mm.dd 요일 hh:mm". 방문 기록이 없으면 현재 문구: "임장 기록이 아직 없습니다"
  - 계획 표시(있을 때만): "예정 MM.DD"(예정일이 오늘 이후) 또는 "미완료 MM.DD"(예정일이 지났는데 완료 안 함), 계획이 2건 이상이면 "… 외 N건"
  - 두 번째 메타 줄: ① 가장 최근 회차가 작성 중이면 "누적 매물 N건 · {미완성 사유}"(사유 우선순위: "필수 문답 N개 미작성" → "매물 N건 작성 중" → "작성 중인 항목이 있습니다") ② 누적 매물이 0이면 "본 매물 없음 · 지역만 확인" ③ 그 외 "누적 매물 N건 · 첫 임장 yyyy.mm.dd"
  - "최고 관심 매물": 단지명, 동·호수, 관심도(별+숫자). 없으면 "아직 없음". 검색어가 매물에 걸린 경우 그 자리에 **검색에 걸린 매물**을 대신 보여 줌
  - 대표 사진 썸네일 최대 2장 + 나머지 장수("+N") (사진이 하나도 없으면 영역 없음)
- **상태**:
  - 로딩: 목록 모양을 본뜬 자리표시.
  - 에러: 현재 문구: "임장 목록을 불러오지 못했습니다." / "네트워크 연결을 확인한 뒤 다시 시도해 주세요. 계속 실패하면 잠시 후 열어 보시면 됩니다." + 다시 시도 동작.
  - 빈 상태(기록이 전혀 없음): 현재 문구: "아직 임장 기록이 없습니다" / "지역을 하나 정해 걸어 보고, 돌아와서 그날의 인상과 본 매물을 남겨 두세요. 매물을 하나도 보지 않은 날도 기록할 수 있습니다." + "첫 임장 계획하기" 동작(INS-06).
  - 검색/필터 결과 없음: INS-05.
  - 요약·필터 개수는 로딩 중에는 숨김 또는 0.
- **결과**: 없음(조회)
- **정책·예외 규칙**:
  - 계획 임장은 "다녀온 임장" 집계(방문 횟수, 누적 매물, 최고 관심 매물, 미완료 요약)에 들어가지 않고 별도로 "예정/미완료" 표시와 개수로만 센다.
  - 동·호수가 비어 있는 매물은 "동·호수 미정"으로 표시한다(모든 임장 화면 공통).
  - 날짜는 시간대 변환 없이 서버 문자열 그대로 해석한다(요일 포함).
  - 목록에는 페이지 이동 동작이 없다. 서버가 주는 한 페이지만 표시한다(확인 필요 참고).
- **데스크톱/모바일 차이**: 계획하기 진입 버튼 위치(INS-06). 필터 버튼은 모바일에서 한 줄 가로 이동. 그 외 없음.
### INS-02 지역 검색
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 지역 목록 상단 검색 입력(접근성 이름 "임장 검색")
- **흐름**:
  1. 검색어를 입력한다. 입력은 즉시 반영되지만 조건 확정(목록 재조회, 주소 `q` 갱신)은 입력이 멈추고 약 0.3초 뒤에 한다. 이 갱신은 뒤로가기 이력을 쌓지 않는다.
  2. 검색어가 공백뿐이면 `q`를 제거한다.
  3. 뒤로가기/앞으로가기, 또는 "필터 해제" 등으로 `q`가 바뀌면 입력창도 그 값으로 맞춘다.
- **입력 항목**:
  | 항목 | 형식 | 필수 | 제약·검증 | 현재 에러 문구 |
  |---|---|---|---|---|
  | 검색어 | 텍스트(검색 입력) | 아니오 | 지역명·지역 설명·단지명·매물명·태그에서 찾음 | 없음 |
  - 입력 안내 문구(현재): "지역, 단지, 매물, 태그로 찾기"
- **표시 데이터**: 일치 항목(INS-01 행). 매물이 검색에 걸린 지역은 그 매물을 행에 표시.
- **상태**: 결과 없음은 INS-05. 로딩/에러는 INS-01과 동일.
- **결과**: 조건에 맞는 지역만 목록에 남음
- **정책·예외 규칙**: 서버 쪽 검색이며 매칭 규칙은 서버 소관.
- **데스크톱/모바일 차이**: 없음
### INS-03 재방문 의사 필터
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 지역 목록의 필터 버튼 묶음(그룹 이름 "재방문 의사 필터")
- **흐름**:
  1. 버튼 5개: "전체 {N}", "다시 임장하고 싶음 {n}", "조금 더 고민 {n}", "재방문하지 않을 예정 {n}", "미정 {n}". 숫자는 전체 기록 기준 개수.
  2. 하나를 고르면 그 조건만 보이고 선택 상태가 표시된다(한 번에 하나, 없으면 "전체").
  3. "전체"를 누르면 필터가 해제된다.
- **표시 데이터**: 필터별 개수
- **상태**: 선택된 필터가 있으면 결과 없음 화면(INS-05)에 "필터 해제" 동작이 추가된다.
- **결과**: 주소 `revisit` 갱신(이력에 쌓임), 목록 갱신
- **정책·예외 규칙**:
  - "미정"(재방문 의사 미입력)은 서버에 조건으로 보낼 수 없어, 서버가 준 목록에서 **가장 최근 회차의 재방문 의사가 없는 지역만 화면에서 걸러** 보여 준다. 개수 표시는 전체 기준.
  - 지원하지 않는 `revisit` 값은 무시하고 "전체"로 취급한다.
- **데스크톱/모바일 차이**: 없음
### INS-04 지역 정렬
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 지역 목록의 정렬 선택(접근성 이름 "정렬")
- **흐름**: "최근 임장순"(기본), "임장 많은 순", "최고 관심도순" 중 하나를 고르면 목록이 다시 조회된다. 기본값을 고르면 주소에서 `sort`를 제거한다.
- **표시 데이터**: 정렬된 지역 목록
- **상태**: 로딩/에러는 INS-01과 동일
- **결과**: 주소 `sort` 갱신(이력에 쌓임)
- **정책·예외 규칙**: 알 수 없는 `sort` 값은 기본값으로 취급
- **데스크톱/모바일 차이**: 없음
### INS-05 검색·필터 결과 없음에서 벗어나기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 기록은 있으나 현재 검색어/필터로 걸러진 결과가 0건일 때
- **흐름**:
  1. 현재 문구: 검색어가 있으면 "'{검색어}'와 맞는 기록이 없습니다", 없으면 "맞는 기록이 없습니다"
  2. 설명 현재 문구: "지역명, 지역 설명, 단지명, 매물명, 태그에서 찾았습니다." 뒤에 필터가 걸려 있으면 " 재방문 의사 필터를 해제하면 더 넓게 볼 수 있습니다.", 아니면 " 다른 검색어로 찾아보세요."
  3. 동작: 필터가 걸려 있으면 "필터 해제"(검색어는 그대로 둠). 항상 "새로 임장 계획하기"(검색어가 있으면 "'{검색어}' 지역 새로 임장 계획하기") → 임장 계획하기(INS-30).
- **상태**: 검색어·필터를 자동으로 지우지 않는다.
- **결과**: 필터 해제 시 `revisit` 제거. 계획하기 이동 시 검색어는 넘기지 않는다(문구만 다름).
- **데스크톱/모바일 차이**: 없음
### INS-06 임장 계획하기 시작 / 질문 관리 진입
- **대상 사용자**: 계획하기는 로그인 사용자 전체, 질문 관리는 **관리자만**
- **진입 경로**: 지역 목록 헤더의 "+ 임장 계획하기", 모바일 폭에서는 화면 하단에서 늘 보이는 "+" 진입 버튼(접근성 이름 "임장 계획하기"), 기록이 없을 때의 "첫 임장 계획하기", 결과 없음 화면의 계획 동작, 지역 상세의 "이 지역 다시 임장"/"이 지역 임장 계획하기"
- **흐름**: 누르면 임장 계획하기(`inspection/register`) 1단계로 이동한다. 관리자에게만 "질문 관리" 버튼이 함께 보이며 누르면 질문 관리(INS-80)로 이동한다.
- **상태**: 관리자가 아니면 "질문 관리"는 보이지 않으며 주소로 직접 들어가도 접근이 거부된다(역할 검사).
- **결과**: 화면 이동
- **정책·예외 규칙**: 지역 상세에서 시작해도 **지역이 미리 선택되지 않는다**(1단계에서 다시 골라야 함 — 확인 필요).
- **데스크톱/모바일 차이**: 데스크톱은 헤더 버튼, 모바일 폭(약 833px 이하)은 헤더 버튼을 숨기고 하단 "+" 진입 버튼으로 대체. "질문 관리"는 양쪽 모두 제목 아래에 유지.
### INS-07 임장 상태 구분 규칙 (계획 / 수정 중 / 완료)
- **대상 사용자**: 모든 임장 화면에 적용되는 공통 규칙
- **진입 경로**: 지역 목록 행, 지역 상세 회차 탭·회차 헤더, 등록 마법사 3단계, 회차/매물 수정
- **규칙**:
  | 서버 상태 | 최초 완료 시각 | 화면 단계 | 배지 현재 문구 |
  |---|---|---|---|
  | 작성 중 | 없음 | 계획 | "계획" |
  | 작성 중 | 있음 | 수정 중(한 번 완료했다가 다시 연 것) | "수정 중" |
  | 완료 | (있음) | 완료 | 배지 없음 |
  - 한 번 완료된 회차는 다시 "계획"이 되지 않는다(완료를 해제해도 "수정 중").
  - **매물 단위** 작성 중 배지("작성 중" + 이유 한 줄)는 회차가 "수정 중"일 때만 표시한다(계획 단계의 매물은 작성 중이 당연하므로 숨김). 이유 우선순위: "필수 문답 N개 남음 — {질문1}, {질문2}…" → "{비어 있는 항목} 미입력"(동·호수 등).
  - 회차 수정 화면 안내(작성 중일 때): 부족한 항목 요약 "임장 일시·재방문 의사 미입력", "매물 N건 작성 중"을 " · "로 이음. 부족한 것이 없으면 현재 문구: "완료 조건은 이미 채워져 있어요 — 아래 버튼으로 완료할 수 있어요."
  - 단계에 따라 기능이 달라진다: 추천 순서 정렬은 완료 단계에서 제공하지 않음(INS-20), 도보 경로 안내 문구가 완료 단계에서 달라짐(INS-19), 지역 목록의 "예정/미완료" 표시(INS-01), 회차 탭 번호(INS-12).
- **데스크톱/모바일 차이**: 없음
### INS-08 공통 표시 규칙 (재방문 의사, 관심도, 태그, 이름)
- **대상 사용자**: 모든 임장 화면
- **규칙**:
  - **재방문 의사**는 아이콘+문구를 항상 함께 쓰고 색만으로 구분하지 않는다. 표시 문구(목록·상세): YES "다시 임장하고 싶음", MAYBE "조금 더 고민", NO "재방문하지 않을 예정"(오류가 아니므로 경고색 금지), 값이 없으면 "미정". 입력 폼의 선택지 문구는 짧게: "살고싶어", "고민", "안살아".
  - **관심도**는 1~5점 별 표시이며 항상 숫자를 함께 보인다. 값이 없으면 "관심도 미입력". 접근성 이름: "관심도 5점 만점에 {n}점". 입력 시에는 5개 중 하나를 고르는 라디오형 입력(접근성 이름 "관심도 5점 만점").
  - **태그**는 표시 시 "#태그" 형태. 목록 행에서는 최대 3개와 초과 개수("+N"), 상세에서는 전부. 서버의 태그 이름에는 "#"이 없다.
  - **매물 이름**: `단지명 · 동·호수`, 동·호수가 없으면 "동·호수 미정".
  - 관심도 요약(매물 상세 헤더): "{n} / 5 · {1 관심 없음, 2 별로, 3 보통, 4 관심 있음, 5 매우 관심 있음}".
  - 날짜·시각: 서버가 주는 시간대 없는 일시를 그대로 "yyyy.mm.dd", "hh:mm"로 표시.
- **데스크톱/모바일 차이**: 없음
### INS-10 지역 상세 보기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 지역 목록 행 선택, 등록 마법사의 "계획 저장" 완료(해당 회차가 선택된 상태로), 매물 상세/편집에서 돌아오기
- **흐름**:
  1. 상위 경로 표시: "임장 › {지역명}"(임장은 목록으로 이동).
  2. 제목에 지역명, 부제에 "{지역 설명 · }임장 {N}회 · 누적 매물 {M}건 · 첫 임장 yyyy.mm.dd"(값이 있는 것만 " · "로 이음).
  3. 헤더 동작: "지역 정보 수정"(INS-11), "이 지역 다시 임장"(INS-06).
  4. 회차가 있으면 회차 탭(INS-12)과 선택 회차 내용(INS-14~INS-20)을 보인다.
- **상태**:
  - 로딩: 헤더·회차 탭·본문 자리표시.
  - 에러: 현재 문구: "지역 정보를 불러오지 못했습니다." / "네트워크 연결을 확인한 뒤 다시 시도해 주세요." + 다시 시도.
  - 회차가 하나도 없음(지역만 만들어진 상태, 또는 유일한 회차를 삭제한 뒤): 현재 문구: "아직 이 지역을 임장한 기록이 없습니다." / "첫 임장을 기록하면 회차별로 쌓입니다." + "이 지역 임장 계획하기" 동작.
- **결과**: 없음(조회)
- **정책·예외 규칙**: `visit` 쿼리가 가리키는 회차를 서버가 선택 회차로 돌려준다. 회차 삭제 후에는 `visit`를 제거(이력 교체)하여 서버 기본 회차를 보여 준다.
- **데스크톱/모바일 차이**: 없음
### INS-11 지역 정보 수정
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 지역 상세 헤더의 "지역 정보 수정" (화면 이동 없이 별도 입력 단계가 열림, 제목 "지역 정보 수정")
- **흐름**:
  1. 현재 지역명·설명이 채워진 입력이 열리고 지역명에 초점이 간다.
  2. "저장"을 누르면 저장하고 닫힌다. "취소" 또는 닫기 동작으로 변경 없이 닫는다.
- **입력 항목**:
  | 항목 | 형식 | 필수 | 제약·검증 | 현재 에러 문구 |
  |---|---|---|---|---|
  | 지역명 | 텍스트 | 예 | 앞뒤 공백 제거 후 비어 있으면 저장 불가(저장 버튼 비활성) | 없음 |
  | 지역 설명 | 여러 줄 텍스트(3줄) | 아니오 | 공백뿐이면 비움으로 저장 | 없음 |
- **상태**: 처리 중 저장 버튼 로딩. 실패 현재 문구: "지역 정보를 저장하지 못했어요. 잠시 후 다시 시도해 주세요."
- **결과**: 성공하면 닫히고 지역 상세·목록 데이터가 갱신된다.
- **정책·예외 규칙**: 지역 삭제 기능은 화면에 없다.
- **데스크톱/모바일 차이**: 없음
### INS-12 회차 전환
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 지역 상세의 회차 탭 묶음(접근성 이름 "임장 회차")
- **흐름**:
  1. 회차가 최신순으로 나열된다. 각 항목: 회차 라벨, 날짜(yyyy.mm.dd), "{요일} {hh:mm} · 매물 N"(0건이면 "매물 없음"), 재방문 의사 표시.
  2. 항목을 누르면 화면 이동 없이 아래 내용만 해당 회차로 바뀌고 주소 `visit`가 갱신된다(뒤로가기가 회차 선택 이력을 따라감).
  3. 키보드: 좌/우 화살표로 이전/다음(양 끝에서 순환), Home/End로 처음/끝 회차 선택 및 초점 이동.
- **표시 데이터**: 회차 라벨 — 계획 회차는 번호 없이 **"계획"**. 완료된 적이 있는 회차끼리 번호를 매기며(최신이 가장 큰 번호) "{N}차". 가장 최근 번호 회차는 "N차 · 가장 최근", 모든 회차를 불러온 상태에서 가장 오래된 번호 회차(번호 회차가 2개 이상일 때)는 "N차 · 처음".
- **상태**: 선택된 회차가 시각적으로 구분되어야 하고(선택 상태 노출), 선택된 탭만 초점 순서에 포함된다.
- **결과**: 선택 회차 내용 교체(새 데이터를 불러오는 동안 기존 화면 유지)
- **정책·예외 규칙**: 번호는 서버의 "임장 횟수"(완료된 적 있는 회차 수)에서 거꾸로 센다. 이전 회차를 추가로 불러와도 번호가 이어진다.
- **데스크톱/모바일 차이**: 없음(모바일은 가로로 이동하는 목록)
### INS-13 이전 회차 더 보기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 회차 탭 끝의 "이전 회차 더 보기" (서버가 더 있다고 알려 줄 때만 표시)
- **흐름**: 누르면 다음 페이지의 회차를 이어 붙여 불러온다(페이지 크기는 서버가 알려 준 값). 더 없으면 버튼이 사라진다.
- **상태**: 불러오는 중 현재 문구: "이전 회차를 불러오는 중…"(버튼 비활성). 실패 현재 문구: "이전 회차를 불러오지 못했어요."
- **결과**: 회차 탭 확장, 번호 라벨 갱신
- **데스크톱/모바일 차이**: 없음
### INS-14 선택 회차 내용 보기
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 지역 상세에서 회차 선택
- **표시 데이터** (위에서 아래 순서, 값이 있는 것만):
  1. 헤더: 재방문 의사(INS-08), 일시 줄 "yyyy.mm.dd 요일 hh:mm · {오전/오후/저녁/밤}"(오전 5~11시, 오후 12~17시, 저녁 18~20시, 그 외 밤), 상태 배지(INS-07), 동작 "이 임장 수정"(회차 수정 INS-50으로 이동), "이 임장 삭제"(INS-16)
  2. 전체 메모(줄바꿈 단위 문단)
  3. 한줄평(따옴표)
  4. 태그 전부
  5. 장점/단점: 줄 단위 목록. 한쪽만 있으면 다른 쪽에 현재 문구: "적어 둔 장점이 없어요." / "적어 둔 단점이 없어요." (둘 다 없으면 영역 없음)
  6. 임장 사진(INS-15)
  7. 방문 순서(INS-18) — 매물이 1건 이상일 때
  8. 추천 순서로 정렬(INS-20) — 매물이 1건 이상일 때
  9. 확인 매물 목록(INS-17)
- **상태**: 매물이 0건이면 INS-17의 빈 상태.
- **결과**: 없음(조회)
- **데스크톱/모바일 차이**: 없음
### INS-15 임장 사진 보기 (회차)
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 회차 내용의 "임장 사진" 영역 (사진이 있을 때만)
- **흐름**: 제목 "임장 사진"과 "{N}장". 처음에는 6장만 보이고, 더 있으면 "사진 {N}장 모두 보기"를 눌러 전부 펼친다(다시 접는 동작 없음). 캡션이 있으면 사진 아래에 표시하고 대체 텍스트로도 쓴다. 캡션이 없으면 대체 텍스트는 비운다.
- **상태**: 지연 로딩. 사진 없으면 영역 없음.
- **데스크톱/모바일 차이**: 없음
### INS-16 회차 삭제 (지역 상세)
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 회차 헤더의 "이 임장 삭제"
- **흐름**:
  1. 확인 절차(화면 이동 없음). 제목 현재 문구: "이 임장 기록을 삭제할까요?"
  2. 설명 현재 문구: "이 회차와 함께 매물 {n}건, 사진 {m}장, 문답 답변이 모두 사라져요. 되돌릴 수 없어요." 지역의 마지막 회차이면 중간에 "이 지역의 마지막 임장 기록이라 지우면 회차가 하나도 남지 않아요." 문장이 추가된다.
  3. 버튼 현재 문구: "삭제할게요" / 취소 "계속 둘게요". 처리 중 삭제 버튼 로딩.
  4. 성공하면 확인 절차를 닫고 기본 회차로 돌아간다(`visit` 제거).
- **상태**: 실패 시 별도 안내 문구는 없다(확인 필요).
- **결과**: 목록·상세 데이터 갱신. 마지막 회차였다면 INS-10의 "기록 없음" 상태.
- **정책·예외 규칙**: 매물·사진·답변이 함께 삭제되며 복구 불가.
- **데스크톱/모바일 차이**: 없음
### INS-17 확인 매물 목록 보기와 매물 상세로 이동
- **대상 사용자**: 로그인 사용자 전체
- **진입 경로**: 회차 내용의 "확인 매물"
- **흐름**:
  1. 제목 "확인 매물"과 "단지 {n}곳 · 매물 {m}건".
  2. 매물은 서버가 준 **방문 순서 그대로** 나열하며 다시 정렬하지 않는다. **연속된** 같은 단지명끼리만 한 묶음으로 보이고(A, B, A 순이면 3묶음), 묶음 머리에 단지명과 "매물 N건"을 보인다. 단지명 자체는 이동 대상이 아니다.
  3. 매물 한 줄: 동·호수("동·호수 미정" 가능), 한줄평, 태그(최대 3), 작성 중 배지+이유(INS-07 규칙), 관심도, 이전 회차 대비 관심도 변화("{n월}보다 {k}단계" + 상승/하락 방향; 같은 지역에서 같은 단지명+동·호수의 바로 이전 회차 기록이 있고 두 관심도가 모두 있으며 값이 다를 때만. 동·호수가 비면 비교 생략), 상세 이동 표시. 한 줄을 누르면 매물 상세(INS-60)로 이동.
  4. 목록 아래에 "+ 매물 추가"(INS-40).
- **상태**: 매물 0건: 현재 문구: "이 날은 매물을 보지 않았습니다" / "동네만 확인한 임장입니다. 이 상태로도 완료된 기록입니다." + "+ 매물 추가".
- **결과**: 매물 상세 이동
- **정책·예외 규칙**: 매물을 하나도 보지 않은 회차도 정상적인 완료 기록이다.
- **데스크톱/모바일 차이**: 없음
